LostLink - Lost and Found Management System

Overview

LostLink is a web-based application designed to simplify the process of reporting and managing lost and found items. It provides an organized platform for submitting, tracking, and managing item reports.

Features

- User registration and login.
- Reporting lost and found items.
- Browsing and managing item reports.
- User profile management.
- Admin dashboard for managing reports.
- Analytics and data visualization.
- Role-based access control.

Technologies Used

- Python
- Streamlit
- Pandas
- JSON
- Git and GitHub

Getting Started

Prerequisites

- Python
- pip

Installation

1. Clone or download the repository.

2. Navigate to the project directory.

3. Install the required dependencies:
   
   pip install -r requirements.txt

Running the Application

Run the application using Streamlit:

streamlit run dashboard.py
